# MMCS 管理界面 —— UI/UX 设计文档

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **内容优先** | 讨论内容（消息流）占据页面主体，导航和操作为辅助 |
| **实时感知** | SSE 流式更新以视觉动画呈现，让用户感知"正在进行" |
| **角色区分** | 每个 AI 角色有独立色彩标识，一眼可辨当前发言人 |
| **渐进呈现** | 流式 token 逐字出现（打字机效果），而非整段闪现 |
| **状态可见** | 所有资源的状态（draft/running/paused/ended）通过 Badge + 颜色明确标识 |

**SSE 流式更新逻辑：**
```
1. EventSource 连接到 /api/v1/sessions/{id}/stream
2. round.start → 显示"第 N 轮开始"提示
3. role.speak → 找到对应角色的消息气泡，逐 token 追加
4. role.done → 标记该角色本轮发言完成
5. round.eval → 显示主持人评估摘要
6. session.paused → 显示暂停提示，启用输入框
7. session.resumed → 恢复流式接收
8. session.ended → 显示"讨论已结束"，提供查看纪要链接
```

## 6. 交互细节

### 6.1 流式打字机效果

```typescript
// useSSE hook 接收到 role.speak 事件后
// 将 token 追加到消息缓冲区
// 组件通过 useState<Message[]> 驱动重新渲染
// 当前正在接收的消息显示闪烁光标 "▊"

// 关键 CSS
.speaking-cursor::after {
  content: '▊';
  animation: blink 1s step-end infinite;
}
@keyframes blink {
  50% { opacity: 0; }
}
```

### 6.2 会话状态切换

| 当前状态 | 可用操作 | 操作后状态 |
|----------|---------|-----------|
| draft | 启动 | running |
| running | 暂停 / 终止 | paused / ended |
| paused | 恢复 / 终止 | running / ended |
| ended | 查看纪要 | — |

操作按钮根据当前状态显示/隐藏，不可用操作用 tooltip 说明原因。

### 6.3 任务卡片拖拽

```
1. dragstart: 设置 dataTransfer 为 task ID
2. dragover: 阻止默认，高亮目标列
3. drop: 读取 task ID，调用 PATCH /api/v1/tasks/:id { status }
4. 乐观更新：先更新 UI，API 失败后回滚
```

## 8. 路由与数据加载

| 路由 | 页面组件 | 数据依赖 |
|------|---------|---------|
| `/` | `WorkspaceListPage` | `GET /workspaces` |
| `/login` | `LoginPage` | — |
| `/register` | `RegisterPage` | — |
| `/workspaces/[id]` | `WorkspaceDetailPage` | `GET /workspaces/:id`, `GET /workspaces/:id/tasks` |
| `/workspaces/[id]/tasks` | `TaskBoardPage` | `GET /workspaces/:id/tasks` |
| `/sessions/[id]` | `SessionDetailPage` | `GET /sessions/:id`, `GET /sessions/:id/messages`, SSE |
| `/sessions/[id]/minutes` | `MinutesPage` | `GET /sessions/:id/minutes` |
| `/roles` | `RoleListPage` | `GET /roles` |
| `/models` | `ModelConfigPage` | `GET /models` |

所有数据通过 TanStack Query 的 `useQuery` 获取，自动缓存和失效。SSE 数据不通过 React Query，通过独立的 `useSSE` hook 管理。
