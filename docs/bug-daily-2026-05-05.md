# MMCS 每日 Bug 清单 — 2026-05-05

## 已修复

| # | 问题 | 影响范围 | 根因 | 状态 |
|---|------|---------|------|------|
| 1 | 启动会话后编排执行失败 `context canceled` | API 后端 | HTTP handler 中异步 goroutine 使用了 `r.Context()`，HTTP 响应返回后 context 被取消 | ✅ |
| 2 | 关闭已关闭的 channel panic (`close of closed channel`) | API 后端 | `startOrchestration` 和 orchestrator 内部都调用了 `close(progressCh)`，重复关闭 | ✅ |
| 3 | 所有会议都是同样内容然后卡住 | 模型调用 | ChatModel 获取失败（API key 未设置等）时回退到模拟模式，产生固定模板内容 | ✅ |
| 4 | 暂停/恢复后用户输入内容未显示也未传给模型 | 会议流程 | `CheckInterrupt`/`WaitForInterrupt` 丢弃了 `ResumeSignal.Message` 字段 | ✅ |
| 5 | 启动后页面卡在"等待讨论开始..."，暂停报错 `ended → paused` | 前端 | 异步 goroutine 的 context 被 `defer cancel()` 提前取消 | ✅ |
| 6 | SSE 事件类型不匹配，前端收不到消息 | 前端通讯 | 后端推送 `agent_speak`、`round_start`，前端监听 `role.speak`、`round.start`，名称不一致 | ✅ |
| 7 | SSE 数据双重序列化，前端解析为字符串而非对象 | 前端通讯 | `Bridge.graphEventToSSE` 将 map JSON 序列化为 string 存入 `Event.Data`，SSE handler 又对 string 做 `json.Marshal` | ✅ |
| 8 | 登录成功但页面不跳转 | 前端鉴权 | `httpCall` 未解包后端 `{code, data}` 响应，前端直接取 `res.token` 始终为 `undefined` | ✅ |
| 9 | 法庭范式启动失败 `作者角色未在角色列表中找到` | 后端编排 | `AuthorRoleID` 未从 session config 提取，配置字段缺失 | ✅ |
| 10 | 重启会议默认标题为角色名而非原标题 | 前端 UI | `RestartSessionDialog` 用 `originalRoles[0].name` 而非 `sessionTitle` | ✅ |
| 11 | 模型配置页 Not Found | 后端路由 | 后端注册了模型 API 但 router 中未添加对应 handler 和路由 | ✅ |
| 12 | JWT 过期时间过短（15min）导致操作被跳转到登录页 | 鉴权 | `config.yaml` 中 `jwt_expiry: "15m"` 改为 `24h` | ✅ |
