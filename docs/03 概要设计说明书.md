### 1.1 编写目的

本文档为「多模型圆桌会议系统」的概要设计说明书，在需求规格说明书的基础上，明确系统的**架构方案、模块划分、模块间接口、数据结构、部署方案与关键设计决策**，作为后续详细设计（详细设计说明书）和编码实现的依据。

### 1.2 适用范围

本文档面向架构师、开发工程师、测试工程师和运维人员，用于指导系统实现与集成。

## 2. 总体设计

### 2.1 设计原则

| 原则 | 说明 |
|------|------|
| **强类型安全** | 利用 Go 的编译期类型检查，Graph 节点间 I/O 类型在编译期验证 |
| **流式优先** | 所有角色发言、状态变更默认以流式（Stream）方式推送 |
| **可观测性** | 全链路 Callbacks 追踪，每个 Graph 节点和 Agent 执行均可审计 |
| **松耦合** | 模型提供商通过 ChatModel 接口统一抽象，新增 Provider 无需改编排逻辑 |
| **人类在环** | Interrupt/Resume 机制确保人在关键环节可介入，不做全自动黑盒 |

### 2.3 核心设计决策

| 决策 | 方案 | 理由 |
|------|------|------|
| 各会话独立 Graph 实例 | 每 Session 创建一个 Eino Graph，互不共享 | 隔离性好，单个 Graph 执行异常不影响其他会话；便于为不同范式定制 Graph 拓扑 |
| Graph 节点为纯函数式 | 每个 GraphNode 无副作用，状态通过 Context 传递 | 可重入、可测试、支持 Interrupt/Resume |
| 流式通信统一用 SSE | 服务端推送使用 SSE 而非 WebSocket | SSE 协议简单、浏览器原生支持、自动重连；双向通信需求少（仅前端→后端用 REST） |
| Agent 异步执行 | 任务执行和验签异步化，通过 Asynq 任务队列解耦 | 长时间任务不阻塞 Graph 主流程；支持失败重试和延迟调度 |
| 全局状态管理 | Graph 全局 State 存储讨论上下文，每个节点可读可写 | Eino 原生支持；避免跨节点参数透传 |
| Provider 接入统一抽象 | ChatModel 接口 + Provider 工厂 | 新增模型提供商只需实现 ChatModel 接口并注册 |

**Session 生命周期：**

```
        用户创建
            │
            ▼
        ┌───────┐
        │ draft │
        └───┬───┘
            │ Start()
            ▼
        ┌───────┐     Pause()    ┌────────┐
```

**并发控制：** 每个 Session 独立运行在自己的 goroutine 中，Graph 执行通过 `context.Context` 传递取消信号。`GraphPool` 管理所有活跃 Session 的 Graph 实例。

```go
type GraphPool struct {
    mu       sync.RWMutex
    sessions map[string]*Session  // sessionID → Session
    maxSize  int
}

func (p *GraphPool) Get(sessionID string) (*Session, bool) {
    p.mu.RLock()
    defer p.mu.RUnlock()
    s, ok := p.sessions[sessionID]
    return s, ok
}

func (p *GraphPool) Register(s *Session) error {
    p.mu.Lock()
    defer p.mu.Unlock()
    if len(p.sessions) >= p.maxSize {
        return ErrPoolFull
    }
    p.sessions[s.ID] = s
    return nil
}
```

### 3.3 orchestrator 模块

核心编排引擎，按范式类型动态构建 Graph 拓扑，处理多轮次循环和条件终结。构建角色提示词时，自动加载角色引用的 Skill 注册表内容并注入 system_prompt。

**Graph 工厂：**

```go
type GraphFactory struct {
    roleService  RoleService
    modelGateway ModelGateway
}

func (f *GraphFactory) Build(paradigm ParadigmType, roles []*Role) (*eino.Graph, error) {
    switch paradigm {
    case ParadigmRoundRobin:
        return f.buildRoundRobin(roles)
    case ParadigmCourtSimulation:
        return f.buildCourtSimulation(roles)
    case ParadigmWeightedEvaluation:
        return f.buildWeightedEvaluation(roles)
    case ParadigmFreeChat:
        return f.buildFreeChat(roles)
    default:
        return nil, ErrUnknownParadigm
    }
}
```

**轮次控制逻辑：**

```
RoundStart
    │
    ▼
ExpertSpeak (并行)
    │
    ▼
ModeratorEval
    │
    ├── ShouldContinue() == true ──→ RoundStart (下一轮)
    │
    └── ShouldContinue() == false ──→ Summarize (结束)

ShouldContinue 判定条件：
  1. 达到最大轮次数 (MaxRounds)
  2. 各角色无新观点 (Moderator 判定)
  3. 用户手动终止
  4. 超时 (Timeout)
```

```go
// Provider 工厂注册
var providerRegistry = make(map[string]ProviderFactory)

type ProviderFactory func(ctx context.Context, config *ProviderConfig) (chat_model.ChatModel, error)

func RegisterProvider(name string, factory ProviderFactory) {
    providerRegistry[name] = factory
}

func GetChatModel(ctx context.Context, binding *ModelBinding) (chat_model.ChatModel, error) {
    factory, ok := providerRegistry[binding.Provider]
    if !ok {
        return nil, fmt.Errorf("unknown provider: %s", binding.Provider)
    }
    return factory(ctx, &ProviderConfig{
        Model:     binding.ModelName,
        APIKey:    decryptAPIKey(binding.EncryptedKey),
        BaseURL:   binding.BaseURL,
        Extra:     binding.Parameters,
    })
}

// init 阶段注册各 Provider
func init() {
    RegisterProvider("openai", NewOpenAIProvider)
    RegisterProvider("anthropic", NewAnthropicProvider)
    RegisterProvider("ollama", NewOllamaProvider)
    RegisterProvider("ark", NewArkProvider)
```

**SSE Hub 实现：**

```go
type SSEHub struct {
    sessionID string
    clients   map[string]chan SSEEvent
    register  chan chan SSEEvent
    unregister chan chan SSEEvent
    broadcast chan SSEEvent
    done      chan struct{}
}

func (h *SSEHub) Run() {
    for {
        select {
        case client := <-h.register:
            h.clients[clientID(client)] = client
        case client := <-h.unregister:
            delete(h.clients, clientID(client))
            close(client)
        case event := <-h.broadcast:
            for _, client := range h.clients {
                select {
                case client <- event:
                default:
                    // client 消费过慢，跳过
                }
            }
        case <-h.done:
            return
        }
    }
}

// 将 Graph Stream 桥接到 SSE Hub
func BridgeGraphToSSE(ctx context.Context, stream *eino.StreamReader[Message], hub *SSEHub) {
    for {
        msg, err := stream.Recv()
        if errors.Is(err, io.EOF) {
            return
        }
        hub.broadcast <- SSEEvent{
            Type:    "role_speak",
            RoleID:  msg.RoleID,
            Content: msg.Content,
        }
    }
}
```

**Agent 执行调度：**

```go
import "github.com/hibiken/asynq"

type AgentExecutor struct {
    agents    map[string]agent.Agent
    tools     map[string]tool.BaseTool
    client    *asynq.Client
    server    *asynq.Server
    inspector *asynq.Inspector
}

const (
    TypeAgentTask = "agent:execute"
)

// 同步执行：在 Graph 节点中直接调用
func (e *AgentExecutor) ExecuteSync(ctx context.Context, agentID string, input any) (any, error) {
    a, ok := e.agents[agentID]
    if !ok {
        return nil, ErrAgentNotFound
    }
    return a.Invoke(ctx, input)
}

// 异步执行：投递到 Asynq 任务队列
func (e *AgentExecutor) ExecuteAsync(ctx context.Context, agentID string, input any) (string, error) {
    payload, _ := json.Marshal(&AgentTask{
        AgentID: agentID,
        Input:   input,
    })
    task := asynq.NewTask(TypeAgentTask, payload,
        asynq.MaxRetry(3),               // 最多重试 3 次
        asynq.Timeout(30*time.Minute),   // 超时 30 分钟
    )
    info, err := e.client.Enqueue(task)
    if err != nil {
        return "", err
    }
    return info.ID, nil
}

// Agent Worker (消费者)
func (e *AgentExecutor) StartWorker(ctx context.Context) {
    mux := asynq.NewServeMux()
    mux.HandleFunc(TypeAgentTask, e.handleAgentTask)

    if err := e.server.Run(mux); err != nil {
        log.Fatalf("asynq server run: %v", err)
    }
}

func (e *AgentExecutor) handleAgentTask(ctx context.Context, t *asynq.Task) error {
    var msg AgentTask
    if err := json.Unmarshal(t.Payload(), &msg); err != nil {
        return err
    }
    a, ok := e.agents[msg.AgentID]
    if !ok {
        return fmt.Errorf("agent not found: %s", msg.AgentID)
    }
    result, err := a.Invoke(ctx, msg.Input)
        if err != nil {
            // 失败重试逻辑
            e.handleFailure(msg, err)
            continue
        }
        // 结果回写
        e.writeResult(msg.TaskID, result)
    }
}
```

### 3.9 minutes 模块

**会议纪要构建（基于 Callbacks 数据）：**

```go
func BuildMinutes(sessionID string, records []CallbackRecord) *MeetingMinutes {
    mm := &MeetingMinutes{
        SessionID: sessionID,
        Rounds:    groupByRound(records),
    }

    for _, round := range mm.Rounds {
        for _, msg := range round.Messages {
            // 收集决策
            if decision := extractDecision(msg); decision != nil {
                mm.Decisions = append(mm.Decisions, decision)
            }
            // 收集分歧
            if disagreement := extractDisagreement(msg); disagreement != nil {
                mm.Disagreements = append(mm.Disagreements, disagreement)
            }
            // 构建评分矩阵
            if score := extractScore(msg); score != nil {
                mm.ScoreMatrix.AddScore(msg.RoleID, score)
            }
        }
    }

    // 构建推理链
    mm.ReasoningChain = BuildChain(records)
    return mm
}
```

```
    case TruncateSummarize:
        将最早 N 轮对话 → ChatModel 总结摘要
        用摘要替换原始对话历史
    case TruncateSlidingWindow:
        保留最近 K 轮对话
        丢弃更早的记录
    case TruncateDropOldest:
        逐轮丢弃最早的消息，直到 ≤ MaxTokens
    }
}
```

```go
type ContextManager struct {
    strategy     TruncationStrategy
    maxTokens    int
    summaryModel chat_model.ChatModel
}

func (m *ContextManager) Compress(history []*Message) ([]*Message, error) {
    total := countTokens(history)
    if total <= m.maxTokens {
        return history, nil
    }

    switch m.strategy {
    case TruncateSummarize:
        return m.summarizeOldest(history)
    case TruncateSlidingWindow:
        return m.slidingWindow(history)
    case TruncateDropOldest:
        return m.dropOldest(history)
    }
}
```

## 6. 运行设计

### 6.1 并发模型

```
请求入口 (HTTP/gRPC)
    │
    ▼
Handler goroutine
    │
    ├── 同步操作 → 直连数据库，返回
    │
    └── 会话操作 → SessionManager goroutine
                      │
                      ├── Graph.Stream() → 启动流式处理 goroutine
                      │                     ├── StreamReader 逐 chunk 读取
                      │                     ├── 转 SSE 事件 → SSE Hub 广播
                      │                     └── Callbacks → 异步写数据库
                      │
                      └── Graph.Interrupt() → 通过 context 发送中断信号
```

**goroutine 模型：**

| 组件 | goroutine 数量 | 说明 |
|------|---------------|------|
| API Server | 按请求数 | 标准 HTTP/gRPC worker pool |
| Session Manager | 1 + N | 1 个管理 goroutine + N 个 Session goroutine |
| Graph Executor | 1 per Session | 每个活跃 Session 一个 goroutine |
| SSE Hub | 1 per Session | 每个 Session 一个广播 goroutine |
| Agent Worker | Asynq 内置 | Worker 由 Asynq Server 管理，按队列深度自动调度 |
| Callbacks Writer | 固定池 (如 5) | 异步批量写审计日志 |

### 6.2 错误处理

```
Graph 节点执行失败
    │
    ├── 可重试错误 (网络超时、Provider 限流)
    │       ├── 重试 3 次，指数退避
    │       └── 均失败 → 节点返回错误 → Moderator 记录并跳过
    │
    ├── 不可重试错误 (参数错误、Provider 不存在)
    │       └── 节点返回错误 → Session 终止 → 通知用户
    │
    └── Session 级错误 (Graph 内部异常)
            └── recover() 捕获 panic
                Session 标记为 failed
                保存已产生的中间结果
                通知用户手动恢复
```

### 6.3 超时控制

| 场景 | 超时 | 处理方式 |
|------|------|---------|
| ChatModel 单次调用 | 60s | Provider 级别超时，可重试 |
| Graph 单轮执行 | 300s | 超时则强制结束本轮 |
| 用户介入等待 | 无限制 | 等待用户 Resume |
| Session 总执行时间 | 24h | 超时强制结束 |
| Agent 异步执行 | 30min | 超时标记失败 |
